- [ ] 테스트용 새 macOS 사용자 또는 깨끗한 Movie Desk 데이터 디렉터리에서 시작했다.

### 라이브러리·원본 안전

- [ ] 한 파일이 실패해도 나머지 파일은 계속 들어온다.
- [ ] 촬영 시각·방향·해상도·재생 길이가 원본과 맞는다.
- [ ] 같은 자산을 다시 넣었을 때 중복 여부를 이해할 수 있다.
- [ ] 앱 재시작 뒤 프로젝트와 미디어가 다시 열린다.
- [ ] 원본을 잠시 분리했을 때 누락 상태가 명확하고 원본 복귀 뒤 회복한다.
- [ ] 종료 후 대표 원본 10개의 크기·수정 시각(가능하면 해시)이 동일하다.

### 전문 편집 경로

자동 초안과 별개로 최소 30초 구간을 타임라인에서 직접 만든다.

- [ ] 미디어 추가, 선택, 이동, 트림, 분할을 수행했다.
- [ ] 두 개 이상의 비디오 트랙과 한 개 이상의 오디오 트랙을 사용했다.
- [ ] 프레임 단위 이동 또는 수치 입력을 사용했다.
- [ ] 전환·효과·키프레임 중 두 가지 이상을 적용했다.
- [ ] 실행 취소·다시 실행 후 결과와 선택 상태가 예상대로다.
- [ ] 재생 중 영상·음성 동기화와 UI 반응이 작업을 막지 않는다.

### 안내형 초안 경로

- [ ] 처음 보는 사람이 분석 리포트의 결론과 다음 행동을 설명할 수 있다.

## 5. 문제와 관찰

심각도는 다음처럼 고정한다.

- **P0:** 완주 불가, 데이터 손실·원본 훼손, 결과 파일 재생 불가, 복구 불가 충돌.

  중요한 기능을 외부 도구로 우회해야 함.
- **P2:** 완주는 가능하지만 의미가 불명확하거나 불필요한 반복·마찰이 있음.
