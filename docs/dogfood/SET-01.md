# SET-01 — 첫 실제 촬영본 선정표

목표는 기능 시연에 유리한 샘플이 아니라, 실제 한 편을 만들 때 Movie Desk의
라이브러리·전문 편집·안내가 함께 버티는지 확인할 **하나의 일관된 촬영본**을 고르는
것이다. 개인 경로와 사람 이름은 이 문서에 기록하지 않는다.

## 완성본 목표

- 한 사건 또는 기간(여행, 가족 행사, 성장 기록 등)을 담은 3~5분 영상.
- 실제 가족 메신저, TV·태블릿 또는 비공개 영상 링크 중 한 곳으로 전송한다.
- 자동 초안을 출발점으로 사용하되, 최소 30초는 타임라인에서 직접 구성한다.
- 원본을 미리 변환하거나 이름을 정리하지 않는다. 카메라·휴대폰에서 나온 구조와
  형식을 가능한 한 그대로 사용한다.

## 선정 기준

전체 **50~200개 파일**, 영상 **30개 이상**, 사진 **15개 이상**, 음악·오디오
**1~3개**를 권장한다. 아래 특성은 서로 겹쳐도 된다.

| 특성 | 최소 목표 | 선택 수 | 확인 |
| --- | ---: | ---: | :---: |
| HEIC/HEIF 사진 | 10 |  |  |
| JPEG/PNG 사진 | 5 |  |  |
| H.264 MP4 또는 MOV | 10 |  |  |
| HEVC(H.265) MOV 또는 MP4 | 10 |  |  |
| Live Photo 정지+영상 쌍 | 3쌍 |  |  |
| 세로 영상 | 5 |  |  |
| 회전 메타가 있는 영상 | 2 |  |  |
| 4K 영상 | 3 |  |  |
| 60fps 또는 가변 프레임률 영상 | 2 |  |  |
| 외부 음악·현장 녹음 | 1 |  |  |
| 흔들림·저노출·중복 등 버릴 후보 | 10 |  |  |
| 긴 클립(2분 이상) | 2 |  |  |

가능하면 서로 다른 기기 2종 이상과 촬영일 2일 이상을 포함한다. 위치 정보가 있는
사진, 음성 없는 영상, 오디오 채널 구성이 다른 영상도 각각 하나 이상 포함한다.

## 폴더 구성

테스트 복제본을 새로 예쁘게 정리하지 않고 실제 구조를 유지한다.

```text
SET-01 (저장소 밖의 사용자 폴더)
├── DCIM 또는 휴대폰 내보내기 구조
├── 카메라 카드 구조(있다면)
├── 별도 음악·녹음
└── known-problems (선택: 손상 또는 미지원임을 이미 아는 파일 1~2개)
```

손상 파일을 넣는 경우 정상 파일과 구분해 두되, 가져오기 때는 같은 배치로 선택해
한 파일의 실패가 전체를 중단시키는지 확인한다.

## 시작 승인 체크

- [ ] 50~200개 범위이며 한 편의 이야기로 묶을 수 있다.
- [ ] HEIC, HEVC, MOV, 세로 영상, 사진, 음악이 실제 원본 형태로 포함됐다.
- [ ] 정상 파일만이 아니라 버릴 후보와 까다로운 파일도 포함됐다.
- [ ] 테스트 중 원본 위치를 유지하고 별도 백업이 있다.
- [ ] 완성본을 실제로 재생할 대상 기기·앱이 정해졌다.
