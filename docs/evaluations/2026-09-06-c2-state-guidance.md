# C2 빈·선택·오류 상태 안내

기준: main `71fabdb`, 구현 브랜치 `codex/c2-state-guidance`.

안내 기둥을 강화하며 기존 전문 편집 도구·모델·원본은 그대로 유지한다.
공통 `StateHint`는 아이콘, 현재 상태와 다음 행동, 선택적인 버튼 하나를 패널 안에 표시한다.
설정이나 안내용 모달을 추가하지 않았다. 미리보기 누락 안내는 영상 위 오버레이에서 패널 내부로 옮겼다.

## 상태 목록

| 패널 | 판정 | 안내와 다음 행동 | 즉시 액션 |
| --- | --- | --- | --- |
| 미디어 | 라이브러리 0개 | 사진·영상 가져오기로 정리·편집 시작 | 기존 파일 선택기 |
| 미디어 | 자산은 있지만 검색 결과 0개 | 검색과 필터를 초기화해 전체 목록 표시 | 검색·복합 필터 초기화 |
| 미디어 | 다중 선택 n개 | 아래 도구로 태그·평점·자동 편집 사용 여부 일괄 지정 | 기존 BulkBar 유지 |
| 미디어 | source health 누락 집합 존재 | 원본 드라이브 연결 또는 파일 재지정 | 재연결 가능한 첫 자산의 파일 선택기 |
| 타임라인 | 클립 0개 | 미디어를 트랙으로 끌거나 제목 추가 | 기존 도구 유지 |
| 타임라인 | 실제 클립 선택 0개 | 클립을 클릭해 이동·자르기·속성 편집 | 기존 클립 선택 유지 |
| 타임라인 | 실제 클립 선택 n개 | 함께 이동하거나 인스펙터에서 첫 클립 조절 | 기존 편집 도구 유지 |
| 타임라인 | 잠긴 트랙 존재 | 해당 트랙 자물쇠로 잠금 해제 | 기존 트랙 잠금 버튼 유지 |
| 인스펙터 | 클립 선택 없음 | 타임라인에서 선택해 위치·길이·효과 조절 | 기존 선택 유지 |
| 인스펙터 | 다중 선택 | 현재 첫 클립을 편집한다는 범위와 단일 선택 방법 명시 | 기존 첫 클립 편집 유지 |
| 미리보기 | 타임라인 클립 0개 | 미디어를 타임라인에 추가해 미리보기 | 가져온 자산만 있을 때도 표시 |
| 미리보기 | 재생 위치에서 누락 소스 발견 | 기존 파일 이름·복구 안내 | 미디어 패널 재연결 경로 |
| 내보내기 | MissingMediaError | 기존 누락 파일 목록·원본 복구·JSON 백업 안내 | 편집으로 돌아가기 |
| 내보내기 | 기타 실패(프리플라이트 포함) | 실패 이유와 원본·범위 확인 후 재시도 안내 | 편집으로 돌아가기 |
| 자동 편집 | 사진·영상 없음 | 기존 분석 전 가져오기 안내 재사용 | 기존 가져오기 유지 |
| 자동 편집 | 분석 미완료·중단 | 이어하기로 남은 분석 실행 | 기존 이어하기 유지 |
| 자동 편집 | 분석 중 | 편집을 계속하거나 분석 중단 가능 | 기존 중단 버튼 유지 |
| 자동 편집 | 분석 완료 후 후보 0개 | 다른 미디어 가져오기 또는 직접 편집 | 실제 buildCandidates 결과 사용, 제외·고정 반영 |

## 검증

- 새 순수 판정 테스트 9개: 빈 목록과 필터 결과 구분, 삭제된 선택 ID 제외, 잠금 독립 판정, 분석 전·중·완료·후보 없음.
- 새 Chromium E2E 2개: 빈 프로젝트의 네 패널 안내와 파일 선택기 실제 가져오기, 한국어 최소 폭에서 검색 결과 없음 → 초기화 → 카드 복귀.
- 기존 `media.dropHere`, `media.noMatches`, `auto.noMedia`, Import·Filters 등 문구 키 유지, en/ko 키를 함께 추가(기존 4칸 들여쓰기 유지).
- 한국어 Chromium 1440×900, 미디어 minSize=12%(약 172px): 빈 미디어·타임라인·인스펙터·미리보기, 자동 편집 빈 상태, 검색 결과 없음 화면을 저장하고 시각 확인했다.
- 새 안내는 단어가 긴 경우에도 패널 폭 안에서 줄바꿈하며, 미디어 헤더는 최소 폭에서 세로 글자나 버튼 잘림 대신 행 단위로 감싼다.
- 화면 증거: [빈 편집기](assets/c2-state-guidance/ko-empty-min-width.png), [자동 편집 분석 전](assets/c2-state-guidance/ko-auto-empty-min-width.png), [필터 결과 없음](assets/c2-state-guidance/ko-filtered-min-width.png).
- 최종 `pnpm gate` **9/9 PASS**: core 107, web 476, desktop 56, scripts 11(단위 합계 650), Chromium E2E 45개 통과; OSV 167개 패키지 취약점 0건, 프로덕션 빌드 성공.
- 기존 C1 안내형 초안 E2E가 의존하는 `auto.noMedia` 문구를 복원한 뒤 전체 게이트를 다시 통과했다.
- en/ko 원문 전체 보존을 별도 비교했으며 각 파일에 새 키 17개만 4칸 들여쓰기로 추가했다.

데스크톱 참조 원본의 파일 재연결 구현은 기존 A4 후속 범위이며 이 변경은 기존 `canRelinkFromFile` 제약을 따른다.
C3 첫 완성률 측정과 실제 사용자 이해도 확인은 후속 배치다.
