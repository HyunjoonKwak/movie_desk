# C2 빈·선택·오류 상태 안내

기준: main `71fabdb`, 구현 브랜치 `codex/c2-state-guidance`; 최초 구현 `7c29497` 리뷰 반영.

안내는 빈 상태·복구가 필요한 상태에서 다음 행동을 제시한다.
정상 타임라인 편집에는 안내 줄이 없고, 잠금 설명은 기존 트랙 자물쇠 툴팁을 사용한다.
공통 `StateHint`는 상태 아이콘·문구·선택적 액션과 info/warning/error 톤을 제공한다.
정보·경고는 `role=status`, 실패는 `role=alert`로 알린다.

## 구현 메모

- 도메인 판정을 media/timeline/autoedit의 `state-guidance.ts`로 분리했다.
- 타임라인 판정은 `useMemo`와 루프로 구현해 stale 선택 ID를 제외하고 `flatMap` 할당을 없앴다.
- 자동 편집 판정은 후보 계산 콜백을 지연 실행한다: 분석 중·미완료·전체 실패에는 `doneAnalyses`/`buildCandidates`를 호출하지 않는다.
- `candidate-window.ts`를 생성과 안내가 공유한다: `max(1200, round(beatsMid × (BPM이 있으면 60000/BPM, 없으면 fallbackCutMs)))`.
- 선택한 음악은 분석이 완료된 뒤 BPM을 읽으며 음악 변경 시 이전 결과를 사용하지 않는다; 음악 분석 중에는 후보 없음 판정을 보류한다.
- 누락 카운트와 첫 누락 자산은 하나의 `useMemo`에서 구한다. 이름이 있는 카드 보기 액션은 기존 가상 레이아웃·강제 마운트 위치를 재사용한다.
- 누락 패널 안내는 프로젝트와 정렬된 누락 집합 서명 기준으로 닫는다. 집합이 바뀌거나 복구 후 다시 누락되면 새 안내를 표시하며 설정·영속화는 추가하지 않았다.
- 빈 상태/누락 미리보기 오버레이는 캔버스 레이아웃에 참여하지 않는다. 정상·누락 전환 시 캔버스 좌표와 크기가 동일함을 E2E에서 확인한다.
- 미디어 `panel-header`의 `flex-wrap`은 최소 폭에서 글자가 세로로 찌그러지거나 버튼이 잘리지 않도록 행 단위로 감싼다. 빈 라이브러리의 Import는 점선 드롭존 CTA 하나로 제공하며 채워진 라이브러리는 기존 헤더 Import를 유지한다.
- 이전 i18n 키는 삭제·수정하지 않았다. 이번 리뷰에서 키 7쌍을 4칸 들여쓰기로 추가하고 필요한 참조만 옮겼다(최초 구현 17쌍과 별도).

## 확인 리뷰 후속

- 음악 분석은 `assetId + opfsPath` 키의 모듈 Promise 캐시를 공유한다. 동시 안내·생성·비트 스냅 및 탭 재진입은 같은 분석 결과를 사용하고 null/예외는 캐시에서 제거해 재시도할 수 있다.
- 음악 안내 effect는 자산 객체 대신 ID·경로·길이 값에 의존한다.
- 점선 드롭존의 바깥 버튼에서 파일 선택기를 연다. 안내는 span이며 중첩 버튼이 없다.
- 카드 reveal에 필요한 위치·DOM·그룹이 없으면 pending 상태를 해제한다. 카드 높이 좌표는 reveal과 마퀴가 `cardTop`을 공유한다.
- 전체 분석 실패에는 부분 성공 문구를 함께 표시하지 않는다.
- 미리보기 누락 안내는 첫 이름과 ‘외 n개’로 요약하고 최대 3줄로 제한해 pointer-events-none 영역의 스크롤 충돌을 없앴다.
- 미디어·타임라인 키 맵도 실제 호출부와 키 실존 테스트가 함께 사용한다. 새 번역은 한영 1쌍만 append했다.

## 검증과 화면

- 순수 판정 12개: 상태·stale 선택·키 실존·모드/BPM 및 1,000회 progress 호출에서 후보 계산 0회를 검증한다.
- 음악 캐시 4개: 동시·후속 호출 공유, ID/경로 분리, null 실패 재시도, 읽기/디코딩 예외 재시도.
- StateHint 렌더 3개: 액션 없음, disabled 버튼, 긴 한국어 파일명·줄바꿈·실패 접근성 역할을 검증한다.
- Chromium E2E 2개: 빈 상태 가시성과 파일 가져오기; 한국어 최소 폭 검색 초기화·정상 편집 안내 부재·잠긴 트랙·누락 캔버스 크기 보존·이름 있는 카드 포커스·안내 닫기·복구 후 새 누락 안내 재표시.
- E2E는 명시적 locale, testid/role 단언과 폭 경계 <180px를 사용한다. 스크린샷은 문서 증빙용으로 생성한다.

데스크톱 참조 원본의 파일 재연결 구현은 기존 A4 후속 범위이며 카드의 기존 `canRelinkFromFile` 제약을 유지한다.
C3 첫 완성률 측정과 실제 사용자 이해도 확인은 후속 배치다.
